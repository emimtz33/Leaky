## Folder Structure
- Detection
Detection contains all leak related content
- Model
Model contains the class defining what is a Leak and what contains it
- Simulation
Stores simulation data like the simulator, its interface for creating sources of flow, and enumerate with all posible water activies
- Storage
Storage stores the lecture interface and the lecture repository class where monitoring is accessed
- src
Contains Alert Manager to send out alerts when a leak is detected.
Main where the simulation is created alongside detection policy and detector. Also is the place where alerts are sent to.
